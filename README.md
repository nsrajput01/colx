# COLX – Community & Collaboration Platform

COLX is a modern web-based platform designed to connect users, facilitate communication, and provide a smooth community-driven experience. The project focuses on building an interactive and user-friendly platform with a clean interface and real-time functionality.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nsrajput01/colx.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code**.

### 3. Run the project

You can use the **Live Server** extension in VS Code or open `index.html` directly in your browser.

## 🔥 Firebase

COLX uses Firebase for backend services such as:

* User authentication
* User data management
* Real-time database operations
* Real-time updates

Make sure to configure your own Firebase project and add the required configuration before running the application.

## ☁️ Cloudinary

Cloudinary is used for image uploading and cloud-based image management.

You should configure your own Cloudinary:

* Cloud name
* Upload preset
* Required upload settings
